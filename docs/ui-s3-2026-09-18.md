# UI S3 周期台账功能证据（2026-09-18）

## 判定

S3 的第一条功能切片通过：Trade Console 现在有只读周期列表和详情读模型。v0 不新增
cycle 表，使用 `decisions.decision_id` 作为周期根，通过已有 `plan_id`、`context_hash`
和 `decision_id` 连接上下文、计划、意图/订单/成交、结算、教训与精确包含周期引用的
审计事件。没有显式引用的事件不会被时间相近关系强行归类。

## 接口

- `GET /api/trade/cycles?limit=8`：返回最近决策周期摘要；limit 服务端限制在 1–50。
- `GET /api/trade/cycles?cycleId=<decision_id>`：返回单个周期详情；未知 id 返回 404。
- 两个接口都经过 DSH authenticated connection，只设置 `cache-control: no-store`，没有
  POST、下单、撤单、模式切换或其它写路径。

## 可复现检查

cd /workspace/dsh-trader

再断言列表同时包含已结算与待结算周期，并逐项验证详情连接关系；不会在空数据库上“通过”。
