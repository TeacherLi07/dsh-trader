## 判定

S2 的 client 只读消费切片通过：Trade Console client 会轮询 `/api/trade/state`，展示
mode/venue、halted、权益、持仓/挂单数量、可信度和重建错误；不会调用交易工具或任何写接口。
当前仍缺真实浏览器视觉验收，探针只验证 bundle 行为契约。

## 可复现检查

```bash
cd /workspace/dsh-trader
pnpm verify
node scripts/client-s0-check.mjs
```

`client-s0-check.mjs` 的 S2 断言：

- fetch path = `/api/trade/state`
- `credentials = same-origin`
- `cache = no-store`
- `POST` 与 `trade_execute_order` 不出现在 client 写路径
- service 未就绪/HTTP 非 2xx 时面板显示 rebuilding/error，而不显示 0

服务端真实 paper profile 的认证状态响应见 `docs/ui-s1-2026-09-17.md`。
