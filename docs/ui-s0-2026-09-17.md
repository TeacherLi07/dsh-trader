## 已确认事实

- `trade` profile 使用 `@deepseek-ai/dsh-base`、`@deepseek-ai/dsh-web-app`、`dsh-trader(link:/workspace/dsh-trader)`，`patchReload=live`。
- `/home/ubuntu/.dsh/profiles/web/node_modules/dsh-token-usage/lib/client.js` 的实际契约是 `window.__ModuleLoader__.load(...)`，工厂返回 `inject`/`apply`，并通过 `ctx.slots.inject(..., () => ctx.slots.register(...))` 注册座位。
- 当前安装的 client 类型确认：`main` 是 root-scoped keyed seat；`sidebar.panellist` 是 root-scoped list seat；二者用同一个自有 key 配对。`ctx.layout.selectPanel()` 负责中央 panel 选择。
- 当前客户端 `ctx.connection` 的真实 API 是 `rpc.call/open`、`generation`、`state`、`reconnect()`、`start()`；Host 侧另有 `connection.fetch.register`。S0 没有新增取数端点，也没有调用 `connection`。
- `trade-supervisor` 使用 `deskSessionId: trade-desk`；窗口触发后对该 session 调用 `agent.followup(createUserMessage(... source.form='notice'))`。消息/工具调用当前仍归属 DSH session/event surface，代码中尚无 cycle key。
